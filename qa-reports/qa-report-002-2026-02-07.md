## Issues

### QA-016 [Major] — Date columns display as epoch milliseconds

**Severity:** Major
**Component:** ResultGrid
**Steps to reproduce:**
1. Execute `SELECT * FROM read_csv('...')` on a CSV with date columns
2. Observe the `start_date` column

**Expected:** Human-readable date format (e.g., `2020-01-15`)
**Actual:** Epoch milliseconds (e.g., `1579046400000`)

**Root cause:** The ResultGrid renders Arrow IPC `Date` type values as raw numbers without formatting. The flechette Arrow decoder returns Date columns as millisecond integers.

---

### QA-017 [Minor] — Query results lost on tab switch

**Severity:** Minor
**Component:** QueryEditor / ResultGrid
**Steps to reproduce:**
1. Execute a query in Query tab
2. Switch to another tab (e.g., Catalog)
3. Switch back to the Query tab

**Expected:** Previous query results still visible
**Actual:** Shows "Execute a query to see results" — results are gone, SQL text persists

**Note:** SQL text is persisted via Dexie, but query results are ephemeral React state. This is likely by design to avoid memory bloat, but may surprise users.

---

### QA-018 [Minor] — No banner/navigation landmark for tab bar

**Severity:** Minor
**Component:** TabBar / App
**Description:** The tab bar area lacks a `banner` or `navigation` ARIA landmark. Screen reader users cannot easily navigate to the tab area via landmark navigation.

---

### QA-019 [Minor] — Settings tab is a placeholder

**Severity:** Minor
**Component:** Settings
**Description:** The Settings tab renders only the text "Settings" with no actual settings controls. This is a known placeholder but may confuse users who open it.

---

### QA-020 [Informational] — Electron CSP warning in dev/package mode

**Severity:** Informational
**Component:** Electron Security
**Description:** Console shows "Electron Security Warning (Insecure Content-Security-Policy)" about `unsafe-eval`. This is expected during development and will not appear in production. Perspective.js WASM may require `unsafe-eval` — a strict CSP should be configured before release.

---

### QA-021 [Informational] — Data Grid / File Import untestable via Playwright MCP

**Severity:** Informational
**Component:** QA Tooling
**Description:** The file import flow (via `+ Import` button or drag & drop) triggers a native OS file dialog that cannot be automated via Playwright MCP's `electron_evaluate`. The Data Grid (Perspective.js) feature requires imported data sources, so it could not be tested in this session. Manual testing or a custom test harness with direct IPC calls is recommended.

## Recommendations

1. **QA-016 (Date formatting):** Add a date formatter in the ResultGrid component that detects `Date`/`Timestamp` Arrow types and renders them as ISO strings or locale-formatted dates.

2. **QA-017 (Results persistence):** Consider caching the last query result per tab in a lightweight structure, or document this as expected behavior.

3. **QA-021 (Test coverage):** Create an automated test harness that calls `window.datspace.ingestion.importFiles([...paths], 'drag_drop')` directly from the renderer to enable end-to-end testing of the import → catalog → Data Grid pipeline without native dialogs.

4. **CSP hardening:** Before release, configure a strict Content-Security-Policy that allows Perspective.js WASM while blocking other `unsafe-eval` usage.
